All Features

More than a pixel map generator — it's your complete LED prep toolkit.

📺

48+ LED Tile Database

Pre-loaded specs for ROE, Absen, Unilumin, INFiLED, Gloshine, and CHAUVET. Select a tile, define your grid, generate. No manual math.

🧊

3D Preview New

See your LED wall layouts rendered in real-time 3D with Three.js. Validate placement, dimensions, and sight lines before you get to site.

🔌

Cable Manager Base

Full cable management — define home runs, spares, and cable types. Export pull sheets for your crew. No more spreadsheets.

🚛

Truck Pack Planner Base

Visual cart and truck loading with drag-and-drop. Generate pack paperwork and manifests. Know exactly what fits before load-in.

🌀

Curved Wall Mode Base

Build curved LED walls with automatic overlap detection. Wall Builder dialog for physical dimensions. Handle concave and convex layouts.

🖥️

Multi-Output Processor Configs Base

Configure outputs for Brompton, Novastar, and Megapixel Helios processors. Split screens across multiple outputs with per-screen wiring settings.

🔲

Multi-Surface Support

Define multiple LED surfaces with independent dimensions and offsets. Handle complex stage layouts in a single project.

📊

Stats Panel

Real-time calculations for total resolution, pixel count, power draw, and weight. Know your specs before you order.

🎯

Alignment Patterns

Center circles, crosshairs, grid overlays, and SMPTE bars for precise panel alignment. See problems before content goes up.

🏷️

Enhanced Labels Base

Auto tile labels with weight control, master offset, and resolution badges. Color-coded alternating tiles. Know which panel is which at a glance.

🖼️

Image Overlay Base

Upload reference images as overlays — crop, resize, and position with handles. Preview your content on the actual wall layout.

📤

Export Everything Base

Unlimited exports in PNG, JPG, and WebP. OBJ mesh export for 3D workflows. disguise CSV export for media server integration.

🎨

Color Swatches Base

16 preset colors plus a full color picker. Color-code your surfaces, groups, and zones for instant visual clarity.

📐

3D Placement Presets Base

Quickly position walls with 3D presets — ground, fascia, header, side fills, and custom angles. Skip the manual positioning.

💻

Desktop App — Mac & Windows

Native desktop app built with Tauri. Runs offline, no browser required. Your data stays on your machine.
