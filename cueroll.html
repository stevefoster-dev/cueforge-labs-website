The safe loop

Lock timecode, take the note, review before anything leaves

Notes are captured locally first and published deliberately. Nothing is pushed to a shared destination because you typed it fast in the dark.

  1. 01

    Chase timecode

    Decode LTC from the audio input the show is already feeding you.

  2. 02

    Capture

    Hit the department key, type, and submit — the song and timecode are stamped for you.

  3. 03

    Collect from the room

    Crew on the local network add their own notes from a phone or laptop.

  4. 04

    Review

    Work the drafts, tidy the wording, and decide what is worth publishing.

  5. 05

    Publish

    Send the approved set to the shared Notion database the production already uses.

Capabilities

Designed for the middle of a tech

Never guess the time again

Exact timecode, exact song

A native decoder reads Linear Timecode from the audio interface, and the setlist turns that number into the song everyone else is talking about.

  • LTC decoded from any audio input, including virtual soundcards
  • Configurable timecode input channel for multichannel interfaces
  • Automatic song detection from the setlist's timecode ranges
  • Mismatch warning when the incoming timecode drifts from the expected range

Keep up with the room

Keyboard-first capture

The interface assumes both hands are busy and the room is dark.

  • Separate note rows per department — lighting, video, cameras, audio, general
  • Single-key focus for each department and tab cycling between them
  • Enter submits; the timecode is captured at the moment of the note
  • Per-song note view so a song can be reviewed as a unit

Include the whole crew

Live Link on the local network

Other people in the room can contribute without being handed the operator's laptop.

  • Local-network sharing that is off by default and started deliberately
  • Phone and laptop clients for crew note entry with department selection
  • Contributions attributed by name
  • Local network only — there is no public internet exposure of a session

Get notes where work happens

Local storage and Notion sync

The show's record lives on the machine running the show. Sharing is a separate, reviewed step.

  • Notes, setlist and track history saved as plain JSON in a folder you choose
  • Works with no internet connection; sync happens when you have one
  • Notion sync into a shared Song Notes database with per-note attribution
  • Drafts tab so unpublished notes are visibly distinct from published ones
  • Approved notes can be surfaced against the grandMA3 workflow

Field fit

Who it is for — and where it stops

Built for

  • Lighting programmers and designers working a tech or dress
  • Video engineers logging content and sync issues against the timeline
  • Production and stage managers running notes sessions
  • Music directors tracking timing and arrangement changes across rehearsals

Outside its authority

  • It does not generate timecode — it reads the show's existing clock
  • It does not control consoles, media servers or playback
  • Live Link is a local-network tool, not a hosted collaboration service
  • Programming cues from timecode is CueMaker's job, not CueRoll's
