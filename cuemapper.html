CueMapper — Projection Mapping Toolkit

Scan your projection surface, build a correspondence map, warp any content to fit. Gray code structured light scanning with real-time content warping. Think Lightform, but open and hackable.

Free
Open source · Python · Cross-platform
View on GitHub → Questions?

How It Works

📡

1. Scan

Display Gray code patterns through your projector. Camera captures each pattern to decode which projector pixel hits which surface point.

🗺️

2. Map

Build a correspondence map: (camera_y, camera_x) → (projector_x, projector_y). This is your surface's DNA.

🎬

3. Warp

Feed any image or video. CueMapper samples the content at each surface location and outputs the warped result through the projector.

Quick Start

# Clone and install
git clone https://github.com/stevefoster-dev/CueMapper.git
cd CueMapper
pip install -r requirements.txt

# Test your camera
python cuemapper.py test-camera

# Run a scan (projector on extended display)
python cuemapper.py scan --proj-width 1920 --proj-height 1080

# Project content onto your surface
python cuemapper.py project --image your_content.jpg
python cuemapper.py project --video animation.mp4

Features

📊

Gray Code Patterns

Binary stripe sequences where only one bit changes between values. Robust to blur at stripe edges. ~2 minute scan time.

📷

Any USB Camera

Works with any USB webcam. 1080p minimum, 4K ideal. Lightform LFC cameras work great if you have one.

🎥

Real-time Warping

Once scanned, warp images and videos in real-time. Test patterns included for alignment verification.

💾

Save Calibrations

Calibration saved to .npz files. Reuse across sessions without rescanning — until you move the projector.

🐍

Python / OpenCV

Pure Python with OpenCV and NumPy. Easy to hack, extend, and integrate into your pipeline.

🔧

Hackable

MIT licensed. Fork it, modify it, integrate it. No black boxes, no license servers, no cloud dependency.
