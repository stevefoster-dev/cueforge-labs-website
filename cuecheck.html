How It Works

👁️

Watch Folder Monitoring

Point CueCheck at your incoming content folder. It watches for new files and validates them automatically — no manual scanning.

🔍

Spec Validation (FFprobe)

Checks resolution, codec, framerate, bitrate, color space, and file size against your custom rule sets. Powered by FFprobe for accuracy.

📝

Auto-Rename to Schema

Incoming files renamed to your naming convention automatically. No more "FINAL_v3_ACTUAL_FINAL.mov" — just clean, consistent names.

🔄

Server Sync

FreeFileSync integration for automatic server distribution. Validated content flows to your media servers without manual copying.

🔔

Slack Notifications

Get pinged when content passes, fails, or needs corrections. Your whole team knows the status without asking.

📋

Custom Rule Sets

Define specs per show, per client, per venue. Save and reuse rule sets across projects. Your standards, enforced automatically.
