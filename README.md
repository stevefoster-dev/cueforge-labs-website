# CueForge Labs Portfolio

Interactive portfolio website featuring an animated forge/anvil logo with circuit animations, nebula regions, and a dark edgy aesthetic.

## Features

- Animated intro sequence with circuit pulse paths converging on the forge
- Teal-glowing anvil logo with circuit traces
- Three interactive nebula regions (Production, Software, About)
- Circuit board background texture in forge view
- Expandable category views with project nodes
- Responsive design

## Tech Stack

- Pure HTML/CSS/JavaScript (no build step required)
- SVG animations
- Canvas-based intro animation

## Usage

Simply open `index.html` in a browser, or deploy to any static hosting service.
