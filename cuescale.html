The safe loop

Load, set the tempos, compare, export as a new pool

CueScale is deliberately small. It does one transformation, shows you what it will do first, and writes a new object so your original pool is untouched.

  1. 01

    Load

    Drop a grandMA3 timecode pool export onto the window, or open it from disk.

  2. 02

    Set tempos

    Enter the source BPM and the target BPM the show has moved to.

  3. 03

    Compare

    Review original and projected timelines side by side in an MA3-style view.

  4. 04

    Export as new

    Write a new pool with its own identifier and a tempo-suffixed name.

Capabilities

One job, done exactly

Predictable maths

Anchored rescaling

The transformation is defined precisely so the result is reviewable rather than mysterious.

  • The anchor is the earliest command event in the pool
  • Events before the anchor pass through unchanged
  • Later events scale by the ratio of source tempo to target tempo
  • Rescaling to the same tempo is required to leave the file byte-identical

See it before you commit

Side-by-side review

The projected result is shown against the original in a familiar MA3-style layout before anything is written.

  • Original and rescaled timelines displayed together
  • Preview is display data — the export file is generated at export time
  • Keyboard export shortcut for a repeated pass across several songs

Do not damage the show

Safe import behaviour

The output is built so grandMA3 treats it as an addition rather than a replacement.

  • Every export gets a newly generated identifier
  • The pool name carries the target tempo so versions stay distinguishable
  • MA3 imports it as a new pool rather than overwriting the original

Keep the show private

Local-only processing

Show files are production-sensitive; CueScale treats them that way by construction.

  • Show files are processed on the machine and are never uploaded by CueScale
  • The desktop shell refuses navigation to anything outside an explicit allowlist
  • Export runs through a privileged check in the application's main process
  • If required licensing trust is missing, the application stays visibly locked rather than silently degraded

Field fit

Who it is for — and where it stops

Built for

  • Lighting programmers whose track tempo moved between rehearsals
  • Designers reusing a programmed song at a different tempo
  • Programmers carrying a timecoded show between versions of an arrangement

Outside its authority

  • It is a focused utility, not a show-programming platform
  • It does not analyse audio or detect tempo — you supply both numbers
  • It does not connect to a console or write into a live showfile
  • Authoring a timecode show from tracks is CueMaker's job

Availability

CueScale is not on public sale.

CueScale is a deliberately small utility in private validation. How it will be distributed — and what it will cost — has not been decided, so no amount is quoted here. Local builds and packaging evidence are not a customer release.
