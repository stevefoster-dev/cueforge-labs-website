02

The transform

Two numbers in, one reviewable result out

CueScale is deliberately small. You supply the tempo the pool was timed at and the tempo the show has moved to; everything else is arithmetic it shows you before it writes anything.

Job — make the maths inspectable

Anchored rescaling, stated on screen

The anchor is the earliest command event in the pool. Events before it pass through unchanged; later events scale by the ratio of source tempo to target tempo. The ratio, the anchor and the resulting filename are all printed before you export.

  • The anchor is the earliest command event in the pool
  • Events before the anchor pass through unchanged
  • Later events scale by the ratio of source tempo to target tempo
  • Rescaling to the same tempo is required to leave the file byte-identical

Boundary CueScale does not analyse audio or detect tempo. You supply both numbers.

Job — see it before you commit

Original and rescaled, stacked

The projected result is drawn against the original in a familiar MA3-style layout, with each event connected to where it will land. You are reading a comparison, not trusting a number.

  • Original and rescaled timelines displayed together on a shared time ruler
  • Markers and command events drawn in both rows with their connections
  • Preview is display data — the export file is generated at export time
  • Keyboard export shortcut for a repeated pass across several songs

Boundary CueScale does not connect to a console or write into a live showfile.

03

The safe loop

Load, set the tempos, compare, export as a new pool

One transformation, shown before it is applied, written as a new object so the original pool is untouched.

  1. 01

    Load

    Drop a grandMA3 timecode pool export onto the window, or open it from disk.

  2. 02

    Set tempos

    Enter the source BPM the pool was timed at and the target BPM the show has moved to.

  3. 03

    Compare

    Review original and projected timelines side by side, with the event span and pool duration recomputed.

  4. 04

    Export as new

    Write a new pool with its own identifier and a tempo-suffixed name, leaving the original alone.

Built for

  • Lighting programmers whose track tempo moved between rehearsals
  • Designers reusing a programmed song at a different tempo
  • Programmers carrying a timecoded show between versions of an arrangement

Outside its authority

  • It is a focused utility, not a show-programming platform
  • It does not analyse audio or detect tempo — you supply both numbers
  • It does not connect to a console or write into a live showfile
  • Authoring a timecode show from tracks is CueMaker's job

05

Availability

In development, no published price

Private Validation — In Development

CueScale is not on public sale.

CueScale is a deliberately small utility in private validation. How it will be distributed — and what it will cost — has not been decided, so no amount is quoted here. Local builds and packaging evidence are not a customer release.

If a tempo change has cost you a rebuild, the useful next step is to tell us the workflow you would want covered.
